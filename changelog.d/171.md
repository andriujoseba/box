### Changed

- `box new --from` still refuses `--cpu`/`--memory`/`--disk`, but no longer
  leaves you there: it prints the `box incus` line for each flag you passed,
  carrying the values you asked for (#171).
- Only for the flags you actually passed, and never a root-size line for a
  container source, whose root rides the storage pool (#171).
- The disk line says it is the one of the three box has not watched work:
  growing a root may want the box stopped, and a `dir` pool may not enforce a
  size at all (#171, #29).
- `box new --help` states that path instead of only the rule (#171).

### Added

- A `--from` clone now says what resources it came up with. The sizing was
  invisible until you ran `box info` and read `limits.*` out of a config dump
  — which is how a clone of a smaller box is discovered under load (#171).
- Every figure in that line is read back off incus. One incus does not answer
  prints nothing, rather than a default from a mint that never ran (#171).
