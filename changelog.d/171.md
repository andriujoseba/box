### Added

- `box new --from` honours `--cpu`, `--memory` and `--disk`. They ride the
  copy itself — incus sizes the clone's volume as it creates it — so there is
  no resize, no restart, and no step inside the guest (#171).
- A clone now says what resources it came up with, read back off incus. That
  sizing was invisible until you ran `box info` and read `limits.*` out of a
  config dump (#171).

### Changed

- `--disk` is refused where the source carries no root device of its own: a
  copy-time override replaces a profile's root device rather than merging
  onto it, and the clone would get a size with no type or path (#171).
- The refusal names which of the two reasons applies, and prints the route to
  size the clone afterwards instead — telling you to stop the box first,
  because `dir` and `btrfs` defer that to the next start (#171, #29).
- `box new --help` states the mechanism and its one precondition, rather than
  a rule that is no longer true (#171).
