### Changed

- `RIG_REF` unset now means rig's LATEST RELEASE, resolved at mint off the releases/latest redirect, instead of `main` — so a released box converges a released rig, which is the combination the drill measured (#150).
- `RIG_REF=<tag>` still pins and `RIG_REF=main` is still the development channel; a mint that cannot resolve the pin fails and says how to pass one, rather than falling back to `main` (#150).
- Only a seed that installs rig resolves anything: `blank` carries no pin token, so it still mints on a host that cannot reach github.com (#150).

### Fixed

- The drill record names the rig pin the mint actually used, read off the box's own stamp, and its reproduction line carries that ref — an unpinned run used to record `main` (#150).
