### Changed

- The four agent templates now create an unprivileged tenant — no sudoers entry — so `sudo` fails inside a fresh agent box. `box root <box>` is the operator's root path. This is mint-time only: cloud-init runs once, so existing agent boxes keep the sudo they were minted with (#177).
- Agent seeds ship `shellcheck` and `python3-venv`, the toolchain their tenant can no longer install for itself; user-local installs still work unprivileged. `blank` and `staging-box` keep sudo — they seed guests that converge themselves (#177).

### Fixed

- A failed tenant convergence now names `box root <box>` then `rig bootstrap <role>` as the re-run, instead of a `sudo` re-run an unprivileged tenant cannot perform (#177).
