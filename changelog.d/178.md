### Changed

- Agent boxes cap `/tmp` at a fixed 1GiB. systemd sized it at 50% of RAM, so
  scratch competed with the agent's working set and raising `BOX_MEMORY` raised
  the ceiling with it — no memory figure fixed that, only a fixed cap (#178).
- The four agent seeds say in `box.env`, beside the memory line, that `/tmp` is
  RAM and that swap is provisioned — the fact belongs next to the setting that
  used to cause it (#178).

### Added

- Agent boxes provision a 4GiB swapfile. Without swap every memory spike was a
  hard OOM-kill with no grace period; swap-in is observable, where a kill is a
  process that was there and then was not (#178).
